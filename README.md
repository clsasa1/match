# Абсолютный МЭТЧ

Визуальная новелла про Иру и Сашу.

Знакомство в приложении, кофейня, договор, Поло и Тепсла, Нижний, Минск, Барановичи.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:8080](http://localhost:8080).

На телефоне (Safari): тап по экрану — дальше, кнопки выбора внизу.

## Сборка

```bash
npm run build
```
